# iot-app

## 简介
欢迎使用iot-app，这是一个基于uniapp框架开发的物联网应用项目。该项目旨在为用户提供一个便捷的物联网设备管理平台。

## 安装步骤

1. 克隆项目到本地：
   git clone [项目Git仓库地址]

2. 进入项目目录：
   cd iot-app

3. 安装依赖：
   npm install

4. 运行项目：
   npm run dev

## 使用方法

- 打开浏览器，访问 [http://localhost:8080](http://localhost:8080) 查看项目。
- 通过uniapp开发者工具可以模拟不同平台（如H5、iOS、Android等）进行预览和调试。

## 功能特性

- 设备管理：用户可以添加、删除、编辑和管理物联网设备。
- 实时监控：展示设备的实时状态和数据。
- 数据分析：提供设备数据的统计和分析功能。
- 通知提醒：当设备状态异常时，及时通知用户。
